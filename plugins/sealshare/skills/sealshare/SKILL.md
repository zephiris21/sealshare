# sealshare — 서버가 못 읽는 링크로 공유

로컬 파일을 **이 컴퓨터에서 암호화**해 올리고 링크를 돌려준다. 여는 열쇠는 링크의 `#` 뒤에만 있고,
브라우저는 `#` 뒤를 서버로 보내지 않는다 — **서버에는 암호문만** 남는다. 내 공유 목록도 암호문으로 저장된다.

## 스크립트 자리

이 스킬 폴더(호출될 때 보이는 **Base directory**) 안의 `scripts/share.mjs` 다. 아래 `$S` 는 그 절대경로다.
플러그인으로 설치됐으면 `${CLAUDE_PLUGIN_ROOT}/skills/sealshare/scripts/share.mjs` 와 같다.
필요한 것은 **Node 18 이상** 하나다(`node --version`). 없으면 설치를 안내하고 멈춘다.

## 할 일

| 사용자가 | 실행 |
|---|---|
| 파일을 링크로 공유해 달라 | `node "$S" share "<파일 절대경로>"` · 제목을 정해 달라면 `--title "…"` |
| 내 공유 목록 | `node "$S" list` |
| 링크를 꺼 달라 | `node "$S" off <링크 또는 id>` — 목록에서 제목으로 찾아 id 를 넘긴다 |
| 관리 페이지(폰·PC 브라우저에서 목록·복사·끄기) | `node "$S" me` |
| 열쇠 등록(「sealshare 열쇠 등록해줘」) | `node "$S" login` — 인자 없이. **«다운로드» 폴더의 `sealshare-key-….txt` 를 스크립트가 직접 읽는다.** 파일이 다른 곳이면 `--file "<경로>"` · 사용자가 열쇠를 대화에 붙였으면 `login <열쇠>`. 서버에 확인한 뒤에만 저장한다 |
| 사용법·처음 시작 | `node "$S" help` 를 실행해 그 안내를 **사용자 말로 짧게** 전한다 |

- 공유할 수 있는 것: **`.html`/`.htm`**(스크립트까지 돈다) · **`.md`/`.markdown`/`.txt`**(깔끔한 문서로 그린다).
- HTML·마크다운이 쓰는 **로컬 그림·CSS·스크립트는 자동으로 안에 묶는다.** 인터넷 주소(CDN 등)는 그대로 둔다.
- 사용자가 파일 이름만 말하면 먼저 찾아서 **절대경로**로 넘긴다. 여러 개가 걸리면 어느 것인지 묻는다.
- 암호문 상한은 25MB다. 넘으면 스크립트가 알려 준다 — 큰 영상·그림을 줄이도록 안내한다.

## 처음 쓰는 사람 (열쇠가 없을 때)

스크립트가 「아직 올리기 열쇠가 없습니다」를 내면: sealshare 는 **운영자가 허락한 사람만 올릴 수 있다.**
운영자에게 받은 **열쇠 파일**(`sealshare-key-이름.txt`)을 «다운로드» 폴더에 두고 「sealshare 열쇠 등록해줘」라고 하면 된다고 안내한다. 열쇠를 지어내지 않는다.
등록이 되면 스크립트가 「열쇠 파일은 이제 지워도 됩니다」라고 알린다 — 그대로 전한다(지우는 것은 사용자가 정한다).

## 사용자에게 알릴 것

`share` 가 찍은 **링크를 그대로** 보여 준다(`#` 뒤까지 전부 — 잘리면 안 열린다). 클립보드에도 복사돼 있다.
함께 한 줄씩:
- **링크를 가진 사람은 누구나 본다** — 로그인·비밀번호가 없다. 대신 링크 없이는 아무도(서버도) 못 연다.
- 공유할 때마다 **새 링크**다. 파일을 고친 뒤 다시 공유하면 새 링크가 나오고, 옛 링크는 옛 내용 그대로다.
- 끄려면 「그 링크 꺼줘」 또는 관리 페이지 — 끄면 즉시 안 열린다(이미 본 사람의 화면·저장본은 못 거둔다).
- 스크립트가 **「못 찾은 로컬 파일」** 을 알렸으면 그대로 전한다 — 받는 쪽에서 그 자리가 비어 보인다.

## 🔴 지킬 것

- 🔴 **열쇠 파일을 `Read` 로 열지 않는다** — 열쇠가 대화에 남는다. 경로만 스크립트에 넘긴다. 올리기 열쇠(`ss_…`)를 대화에 되풀이해 적지도 않는다. 설정 파일은 `~/.sealshare/config.json`.
- `me` 가 주는 **관리 페이지 주소에는 열쇠가 들어 있다** — 사용자 본인에게만 보여 주고, 남에게 보내라고 하지 않는다. 문서를 남에게 줄 때는 문서 링크(`/s/…`)다.
- 비밀번호·개인정보·회사 기밀이 든 파일이면 공유 전에 한 번 확인한다 — 링크는 전달되면 누구나 연다.
- 사용자가 시키지 않은 파일을 올리지 않는다.
