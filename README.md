# 🔒 sealshare

**클로드 코드에서 한마디로, 내 HTML·마크다운 파일을 링크로 공유합니다.**
받는 사람은 링크만 누르면 브라우저에서 바로 봅니다(폰·아이패드 포함). 서버는 내용을 읽을 수 없습니다.

```
나      > 이 스토리보드 링크로 공유해줘: storyboard.html
클로드  > https://sealshare.pages.dev/s/…#…   (클립보드에 복사됨)
```

## 쓰려면 — 운영자의 허락이 필요합니다

sealshare 는 **운영자(zephiris21)의 지인만 올릴 수 있는** 비공개 도구입니다.
운영자에게 직접 부탁하면 **열쇠 파일**(`sealshare-key-이름.txt`)을 보내 줍니다. 그 파일이 허가증입니다.

- 링크를 **여는 것**은 누구나 할 수 있습니다(설치·가입 없음)
- 링크를 **만드는 것**은 열쇠를 받은 사람만 할 수 있습니다
- 열쇠 파일은 남에게 주지 마세요. 잃어버렸으면 운영자에게 말하면 새로 줍니다

## 설치 (한 번)

클로드 코드에서:

```bash
claude plugin marketplace add zephiris21/sealshare
claude plugin install sealshare@sealshare
```

받은 열쇠 파일을 **다운로드 폴더**에 둔 채로, 클로드 코드를 다시 켜고 이렇게 말합니다:

```
sealshare 열쇠 등록해줘
```

「○○ 님으로 확인됐습니다」가 나오면 끝입니다. 열쇠 파일은 지워도 됩니다. (Node 18 이상이 필요합니다)

## 쓰는 법 — 말로 하면 됩니다

| 이렇게 말하면 | |
|---|---|
| 「이 파일 링크로 공유해줘: 파일이름」 | 링크가 나오고 클립보드에 복사됩니다 |
| 「내 공유 목록 보여줘」 | 지금까지 만든 링크 |
| 「그 링크 꺼줘」 | 그 링크가 더는 안 열립니다 |
| 「공유 목록 관리 페이지 열어줘」 | 폰·PC 브라우저에서 목록 보기·링크 다시 복사·끄기 — 즐겨찾기해 두세요 |
| 「sealshare 사용법」 | 짧은 안내 |

- 공유할 수 있는 것: `.html`(애니메이션·스크립트까지 그대로) · `.md` `.txt`(읽기 좋은 문서로)
- 파일이 쓰는 그림·스타일은 자동으로 함께 들어갑니다. 한 건에 25MB까지
- 공유할 때마다 **새 링크**입니다. 파일을 고쳐 다시 공유하면 새 링크가 나오고, 옛 링크는 옛 내용 그대로입니다

## 알아 둘 것

- **링크를 가진 사람은 누구나 봅니다** — 구글 문서의 「링크가 있는 모든 사용자」와 같습니다. 전달되면 전달받은 사람도 엽니다
- 내용은 내 컴퓨터에서 암호화되어 올라가고, 여는 열쇠는 링크 안에만 있습니다. **서버와 운영자는 내용도, 내 목록도 볼 수 없습니다**
- 링크를 끄면 바로 안 열립니다. 다만 이미 본 사람의 화면·저장본은 거둘 수 없습니다
- 관리 페이지 주소에는 내 열쇠가 들어 있습니다 — 본인만 쓰세요
