# 🔒 sealshare

**클로드 코드에서 한마디로, 로컬 HTML·마크다운을 «서버도 못 읽는» 링크로 공유합니다.**

```
나      > 이 스토리보드 링크로 공유해줘: storyboard.html
클로드  > https://sealshare.pages.dev/s/MmYvj97ZBJotinprTOjWaw#qd21…   (클립보드에 복사됨)
```

받는 사람은 링크만 누르면 브라우저에서 바로 봅니다(아이패드·폰 사파리 포함). 설치도 로그인도 필요 없습니다.

---

## 무엇에 쓰나

- 클로드 코드로 만든 **스토리보드·발표·시안 HTML** 을 동료·지인에게 보여 줄 때 — 스크립트·애니메이션까지 그대로 돕니다
- **마크다운 문서**(기획서·회의록·조사)를 깔끔한 읽기 화면으로 보낼 때
- 파일로 보내면 안 열리는 곳(아이패드 «파일» 앱은 HTML 스크립트를 안 돌립니다)에 링크로 보낼 때

## 🔑 누가 쓸 수 있나 — 운영자의 허락이 필요합니다

sealshare 는 **운영자(zephiris21)와 그 지인만 올릴 수 있는 비공개 공유 도구**입니다. 코드는 공개지만 서버는 개인이 운영합니다.

| | 누가 | 필요한 것 |
|---|---|---|
| **올리기**(링크 만들기) | 운영자가 등록한 사람만 | **올리기 열쇠**(`ss_…`) — 운영자에게 직접 받습니다 |
| **보기**(링크 열기) | 링크를 가진 누구나 | 없음 |
| **사람 추가·빼기** | 운영자만 | 서버(Cloudflare 계정) 접근 |

**쓰고 싶으면**: 운영자에게 직접 요청하세요(아는 사이일 때만). 운영자가 열쇠를 하나 만들어 건네 줍니다.
그 열쇠가 **허가증**입니다 — 이름·계정 가입은 없고, 열쇠를 가진 사람이 곧 등록된 사람입니다.
그래서 **열쇠는 남에게 주지 마세요.** 잃어버렸거나 샌 것 같으면 운영자에게 말하면 그 열쇠만 끄고 새로 줍니다.

> 운영자가 아닌 분이 직접 서버를 세워 쓰고 싶다면 아래 「운영자용」대로 자기 Cloudflare 계정에 띄우면 됩니다(무료 한도 안).

## 설치 (클로드 코드 · 2분)

```bash
claude plugin marketplace add zephiris21/sealshare
claude plugin install sealshare@sealshare
```

그다음 클로드 코드를 다시 켜고, 운영자에게 받은 열쇠를 등록합니다:

```
sealshare 열쇠 등록해줘: ss_xxxxxxxxxxxxxxxx
```

「등록했습니다 — ○○ 님으로 확인됐습니다」가 나오면 끝입니다. 필요한 것은 **Node 18 이상** 하나입니다.
업데이트: `claude plugin update sealshare@sealshare`

## 쓰는 법 — 클로드 코드에 말로

| 이렇게 말하면 | 이렇게 됩니다 |
|---|---|
| 「이 파일 링크로 공유해줘: 스토리보드.html」 | 링크가 나오고 클립보드에 복사됩니다 |
| 「내 공유 목록 보여줘」 | 지금까지 만든 링크 |
| 「그 링크 꺼줘」 | 그 링크가 더는 안 열립니다 |
| 「공유 목록 관리 페이지 열어줘」 | 폰·PC 브라우저용 **관리 페이지** 주소 — 즐겨찾기해 두면 어디서든 목록 보기·링크 다시 복사·끄기 |
| 「sealshare 사용법」 | 이 안내 |

- 공유할 수 있는 것: `.html` `.htm`(스크립트까지 돕니다) · `.md` `.markdown` `.txt`(읽기 좋은 문서로 그립니다)
- HTML·마크다운이 쓰는 **로컬 그림·CSS·스크립트는 자동으로 안에 묶입니다.** 인터넷 주소(CDN 등)는 그대로 둡니다
- 한도: 공유 한 건 25MB(암호화 후)
- **공유할 때마다 새 링크**입니다 — 파일을 고쳐 다시 공유하면 새 링크, 옛 링크는 옛 내용 그대로
- 관리 페이지 주소에는 올리기 열쇠가 들어 있습니다 — **본인만 쓰고 남에게 보내지 마세요**

### 에이전트(클로드)에게

설치하면 `sealshare` 스킬이 생깁니다. 위 표의 말에 스킬이 발동하고, 스킬 폴더의 `scripts/share.mjs` 를 부릅니다
(`share <파일> [--title]` · `list` · `off <링크|id>` · `me` · `login <열쇠>` · `help`). 자세한 규칙은
`plugins/sealshare/skills/sealshare/SKILL.md` 에 있습니다 — 올리기 열쇠를 대화에 되풀이하지 않고, 링크는 `#` 뒤까지 그대로 전합니다.

## 어떻게 작동하나

```
내 컴퓨터(클로드 코드)                         서버(Cloudflare Pages + R2)            받는 사람(브라우저)
────────────────────                         ─────────────────────────            ──────────────────
파일 + 로컬 그림·CSS 를 한 파일로 묶음
→ gzip → AES-256-GCM(무작위 열쇠)로 봉함
→ 암호문만 올림 ─────────────────────────→   암호문 저장(열 수 없음)
링크 = 주소/s/<번호>#<열쇠>  ──────────(메신저 등으로 전달)──────────────────→  링크를 연다
                                                                                 # 뒤 열쇠는 서버로 안 감
                                             암호문을 내줌  ─────────────────→  브라우저 안에서 풀어 보여 줌
```

| 지키는 것 | 방법 |
|---|---|
| **서버는 내용을 못 읽는다** | 암호화·복호화가 전부 양 끝(내 컴퓨터·받는 브라우저)에서 일어납니다. 열쇠는 링크의 `#` 뒤에만 있고 브라우저는 `#` 뒤를 서버로 보내지 않습니다 |
| **운영자도 내 목록을 못 본다** | 「내 공유 목록」도 암호문입니다. 올리기 열쇠에서 서버로 보내는 **인증값**과 서버로 안 가는 **목록 열쇠**를 따로 뽑습니다 — 서버는 인증값의 해시만 알아서 열쇠 원문도 목록도 모릅니다 |
| **공유한 HTML 은 격리해서 띄운다** | 별도 주소(`frame.sealshare.pages.dev`)의 틀 안에서 돕니다 — 그 안의 스크립트는 열쇠가 있는 보기 화면에 닿지 못합니다. 보기 화면에는 엄격한 보안 정책(CSP)이 걸려 있습니다 |
| **끄면 사라진다** | 끄기 = 서버에서 암호문 삭제. 즉시 안 열립니다 |

**한계** — 링크가 전달되면 전달받은 사람도 엽니다(구글 문서의 「링크가 있는 모든 사용자」와 같습니다). 이미 본 사람의 화면·저장본은 끌 수 없습니다.
링크는 브라우저 방문 기록에 남습니다.

## 운영자용

```bash
cd server
npm install
node admin.mjs add <이름>      # 올리기 열쇠 발급 — 서버에 반영·배포·통하는지 확인까지 한 뒤 열쇠를 한 번만 보여 줍니다
node admin.mjs remove <이름>   # 그 사람의 열쇠 끄기(그 사람이 이미 만든 링크는 그대로 열립니다)
node admin.mjs list
npm run deploy                                                   # 본 주소 배포
npx wrangler pages deploy --branch frame --commit-dirty=true     # 틀 주소(frame.…) 배포 — frame.html 을 고쳤을 때
```

서버에는 열쇠에서 뽑은 인증값의 **해시만** 올라갑니다(Pages 비밀값 `UPLOADERS`). 열쇠 원문은 어디에도 저장되지 않습니다.

## 구조

```
.claude-plugin/marketplace.json          마켓플레이스(설치 명령이 읽는 목록)
plugins/sealshare/                       클로드 코드 플러그인
  skills/sealshare/SKILL.md              스킬 — 언제 무엇을 실행하나
  skills/sealshare/scripts/share.mjs     묶기 · 암호화 · 올리기 · 목록 · 끄기 · 관리 페이지 (의존성 없음)
server/                                  Cloudflare Pages
  functions/api/s/index.js               POST 암호문 받기(인증값 확인)
  functions/api/s/[id].js                GET 암호문 내주기 · DELETE 끄기
  functions/api/me/list.js               GET·PUT 내 공유 목록(암호문)
  functions/api/me/whoami.js             열쇠 확인
  functions/s/[id].js                    /s/<번호> → 보기 화면 (+ CSP)
  public/viewer.html · viewer.js         브라우저에서 풀기 · HTML 은 틀로 · md 는 marked 로
  public/frame.html                      별도 주소에서 HTML 을 띄우는 틀
  public/me.html · me.js                 관리 페이지
  lib/shared.js                          인증·공용
  admin.mjs                              올리는 사람 관리
```

비슷한 도구와 차이 — StatiCrypt·PageCrypt 는 HTML 을 링크 속 열쇠로 푸는 **파일**을 만들 뿐 올릴 곳·올리는 사람 제한·끄기가 없고,
PrivateBin 등 종단간 암호화 붙여넣기 도구는 HTML 을 페이지로 띄우지 않습니다(스크립트를 지웁니다). (2026-09-27 조사)

마크다운 렌더러: [marked](https://github.com/markedjs/marked)(MIT, `server/public/vendor/`).
